# 🚗 Car Rental System

A full-stack Car Rental System developed using **Node.js, Express.js, HTML, CSS, and JavaScript**. The application allows users to browse available cars, register, and rent vehicles through a simple web interface.

> 🚧 **Project Status:** Currently under development.

---

## ✨ Features

- User Registration
- Car Rental Page
- Responsive User Interface
- Backend Server using Express.js
- Interactive Animations
- Clean UI Design

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/PremKumar1801/Car_Rental_System.git
```

### Install dependencies

```bash
npm install
```

### Run the server

```bash
node server.js
```

Open your browser and visit:

```
http://localhost:3000
```
